**Date gathered: 2026-08-04.** The competitive community's early-spoiler read on which NEW Hobbit
cards will see Legacy / eternal play, registered as a predictor in its own right (per the Marvel
protocol). **Integrity:** the framework verdicts were committed at `51f44af` **before** this
community sweep — the git timestamps prove the framework predictor was produced blind (no

## Framework vs community — the discriminating disagreements
- **Agreement — Riddles in the Dark** (both FRINGE): the consensus pick.
- **Community more bullish (framework said NOT PLAYED): Bilbo Thief in the Night, Gandalf
  Goblins' Bane, Gollum, An Unexpected Party.** These four are the split. If they flop and only
  Riddles sticks, the framework wins; if the community's picks see play, the community wins — the
  same shape as the Marvel test, where the community caught Fantasticar and the framework didn't.
