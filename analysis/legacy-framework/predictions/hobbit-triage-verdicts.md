## Method
Framework threshold rule (`evaluation.md` Q6–Q7): a card earns play iff it beats the **weakest
incumbent** in its functional slot, conditional on pool + field. Cheap-card bias (≤1 strongly
favored, ≥4 penalized unless it cheats cost / ends the game). Err toward recall.

## Headline: a low-Legacy-impact set
The Hobbit is a tribal / Limited / Commander-centered UB set (Dwarves + Equipment, Elves +
landfall, Goblins + Amass, Sagas, "Storied," Adventures, battlecruiser Dragons). Sweeping all 207
new cards for the **format-warping signal types** — free spells, fast mana, mana denial,
sub-2-mana cantrips/permission, lock pieces — finds **none at Legacy rates**: no Sol-land, no
ritual, no pitch spell, no Wasteland/Stifle, no cost-cheat that ends the game. The nonbasic lands
all enter tapped; removal is 3-mana-plus (below Swords/Push/Bolt); counters are 3-mana (below
Counterspell/Daze/Force). **Humility flag:** the framework *under-called* Marvel's format-warper
(Fantasticar) — but that card had a genuine free-cast rate; nothing here has an analogous engine.
